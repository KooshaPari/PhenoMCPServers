# Research

## Codebase Findings

- `README.md` describes a privacy-first user-status runtime for Codex and
  Claude agents.
- The repo exposes CLI and MCP surfaces for local iMessage/status helpers,
  derived presence, session events, and local status publication.
- Previous badge evidence exists on older branches, but the active
  `ci/pin-trufflehog` README lacks the badge.

## Decision

Agent User Status remains a direct Sladge target because it provides local
agent communication and presence context surfaces for Codex/Claude sessions.
